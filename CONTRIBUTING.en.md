# Contributing

Chinese version: [CONTRIBUTING.md](./CONTRIBUTING.md)

Contributions to Open Pill Reminder are welcome.

Contribution areas:

- Firmware development
- Web console frontend
- Hardware schematics and PCB
- Enclosure and mechanical design
- Documentation
- Localization
- Testing and issue reports

Before submitting a PR, please describe:

- What changed
- How it was tested
- Which hardware model was involved

Project direction constraints:

- Changes that move the project toward cloud dependency are not accepted
- Changes that move the project toward an account system are not accepted
- Changes that move the project toward a medical judgment system are not accepted

Version 0.1 principles:

- Offline first
- Local storage
- Minimal and reliable
