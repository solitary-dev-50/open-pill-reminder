# 第一版范围

## 第一版必须实现

### 提醒配置

- 用户可在 Web 页面自由添加每天的提醒时间
- 每天最多 8 个提醒
- 每个提醒包含：
- `id`
- `time`
- `enabled`

### 到点提醒

- 到点后触发蜂鸣器
- 到点后触发 LED
- 到点后在 OLED 上显示提醒信息

### 用户确认

- 用户通过确认键确认本次提醒
- 确认后停止当前提醒
- 记录该提醒已确认
- 记录确认时间

### 重复提醒

- 未确认时按照 `repeat_interval_minutes` 再次提醒
- 最多重复 `max_repeat_count` 次
- 达到最大次数后结束当次提醒流程

### 本地记录

- 记录按日期保存
- 保存今日每条提醒的确认状态和确认时间
- 配置和记录都保存在本地

### Web 控制台

- 查看当前设备时间
- 查看提醒列表
- 新增提醒
- 修改提醒时间
- 删除提醒
- 启用或停用提醒
- 设置重复提醒间隔
- 设置最大重复次数
- 测试蜂鸣器
- 测试 LED
- 测试 OLED 或立即触发提醒

## 第一版不做

- 药品名称
- 剂量
- 星期选择
- 云同步
- 手机 App
- 账号体系
- 家属远程通知
- 历史图表
- 复杂导出
- 电池供电与充电管理
- 复杂外壳结构

## 第一版边界

第一版只证明一个闭环：

`配置提醒时间 -> 到点提醒 -> 用户确认 -> 本地记录`

任何超出这个闭环的能力，都不应抢占第一版开发资源。
