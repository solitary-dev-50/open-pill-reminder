# Version 0.1 Scope

Chinese original: [01_v1_scope.md](./01_v1_scope.md)

Version 0.1 focuses on the smallest practical loop:

- Add daily reminder times in the web console
- Trigger local alerts on the device
- Confirm with the `OK` button
- Save confirmation results locally

Included scope:

- Up to 8 daily reminders
- Local configuration storage
- Local daily records
- Repeat interval and maximum repeat count configuration
- Basic hardware test actions in the web console

Excluded scope:

- Cloud sync
- App accounts
- Mobile app
- Medicine metadata
- Dosage
- Medical judgment
