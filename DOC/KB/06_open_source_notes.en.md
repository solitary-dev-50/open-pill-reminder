# Open Source Notes

Chinese original: [06_open_source_notes.md](./06_open_source_notes.md)

Open Pill Reminder is intended to be open source not only in firmware but also in hardware documentation and PCB files.

Open source publishing for this repository should keep these pieces aligned:

- Clear scope
- Clear disclaimer
- Clear licensing split between code, documentation, and hardware
- Contribution rules that protect the offline-first and non-medical direction
