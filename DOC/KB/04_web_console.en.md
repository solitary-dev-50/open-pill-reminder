# Web Console

Chinese original: [04_web_console.md](./04_web_console.md)

The local web console is intended to be simple and operational.

Current responsibilities:

- Show current device status
- Show whether time is synced
- Sync browser time to device
- Add, edit, delete, enable, and disable reminders
- Configure repeat interval and maximum repeat count
- Trigger test actions for buzzer, LED, OLED, and reminder flow
- Show today's records

The web console remains local-only and does not depend on cloud services.
