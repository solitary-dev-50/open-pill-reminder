# 项目定位

## 一句话定义

小药记 / Open Pill Reminder 是一个离线优先的开源服药提醒设备，用于本地提醒用户并记录用户是否完成手动确认。

## 它是什么

- 一个本地服药提醒器
- 一个开源硬件项目
- 一个开源固件项目
- 一个可放在普通药盒旁边使用的小设备
- 一个强调可复现和可维护的极简系统

## 它不是什么

- 不是医疗设备
- 不是药品容器
- 不是智能药柜
- 不是云端健康管理系统
- 不是药品识别或剂量判断系统
- 不是替代医生、药师或护理人员的工具

## 项目价值

这个项目解决的是现实中的小问题：

- 忘记吃药
- 不记得今天吃没吃
- 不想依赖手机提醒
- 想要一个断网也能工作的本地提醒器

## 第一版原则

1. 实用优先
2. 离线优先
3. 本地优先
4. 先跑通闭环，再考虑扩展
5. 不做医疗承诺

## 正确表达

可以这样描述：

- 本地服药提醒
- 本地确认记录
- 离线优先
- 开源硬件与开源固件
- 帮助用户减少遗忘

不要这样描述：

- 防止漏服
- 保证按时服药
- 医疗级提醒
- 适合所有患者
- 自动判断药品或剂量
