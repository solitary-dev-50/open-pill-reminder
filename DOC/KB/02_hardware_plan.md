# 最小硬件方案

## 目标

第一版硬件目标不是小型化，也不是量产外观，而是快速做出一个可运行、可复现、可拍演示视频的最小系统。

## 核心器件

- ESP32-C3
- 0.96 寸 I2C OLED
- 有源蜂鸣器
- 确认按键
- 设置按键
- 单颗 WS2812 或普通 LED
- USB-C 供电

## 推荐原则

- 优先使用现成模块
- 优先降低焊接和调试复杂度
- 优先保证稳定和可复现

## 输入输出角色

### 输入

- `OK`：确认当前提醒
- `SET/BACK`：保留为辅助交互或调试键

### 输出

- 蜂鸣器：声音提醒
- LED：状态或提醒闪烁
- OLED：显示当前时间、下一次提醒、提醒状态

## I2C 设计

- OLED 使用 I2C
- 若后续引入 RTC，可与 OLED 共用 I2C 总线
- 需要确认设备地址不冲突
- 只保留一组合适的上拉电阻

## 蜂鸣器建议

- 第一版优先使用有源蜂鸣器
- 若蜂鸣器电流较大，增加三极管或 MOS 管驱动
- 不建议第一版优先使用无源蜂鸣器，以免引入 PWM 复杂度

## 按键建议

- 一端接 GPIO，一端接 GND
- 使用内部上拉
- 固件必须做消抖

## 供电建议

- 第一版使用 USB-C 供电
- 不做电池方案
- 不做充电管理

## 结构与外壳约束

- 小药记 PCB 目标为适配树莓派 `Raspberry Pi 4B` 外壳
- PCB 外形需要考虑外壳内部可安装空间
- PCB 安装孔位需要与外壳固定点匹配
- `USB-C` 接口位置需要对齐外壳开孔
- `OK` / `SET-BACK` 按键位置需要对齐外壳按键孔

这部分约束会直接影响：

- 板框外形
- 元件布局
- 接口朝向
- 按键位置
- 后续 3D 外壳适配

## 丝印建议

- `OK`
- `SET/BACK`
- `BUZZER`
- `OLED`
- `LED`
- `USB-C`
- `3V3`
- `GND`
- `SDA`
- `SCL`
- `Open Pill Reminder V0.1`

## 设计边界

设备是提醒器，不是药品容器。  
它应放在普通药盒旁边使用，而不是把药片直接纳入设备结构。
