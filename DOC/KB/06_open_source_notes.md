# 开源发布备注

## 开源定位

这个项目的价值不在“功能堆叠”，而在：

- 小
- 实用
- 离线
- 可复现
- 便于他人理解和复做

## 第一版适合公开的内容

- 项目介绍
- 设计文档
- 固件源码
- Web 页面源码
- 硬件连接说明
- BOM
- 使用说明
- 演示视频

## 发布时应强调

- 这是开源提醒设备
- 第一版目标是跑通核心闭环
- 项目不属于医疗设备
- 不依赖云端和手机 App

## 不要在第一版发布中强化的内容

- 智能医疗
- 健康管理平台
- 自动化药品识别
- 远程看护系统
- 复杂商业化叙事

## 开源材料优先级

1. 清晰 README
2. 连接图或原理图
3. 可编译固件工程
4. Web 控制台截图
5. 演示视频
6. BOM 和接线说明

## 发布目标

第一版发布的目标应是：

- 让别人能理解项目边界
- 让别人能复现最小系统
- 让别人看到核心闭环已经跑通
