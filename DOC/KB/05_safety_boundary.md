# 安全边界与免责声明

## 必须声明

本项目不是医疗设备。  
本项目不提供医疗建议。  
本项目不判断药品种类、剂量或治疗方案。  
本项目只做本地提醒和用户确认记录。

## 中文声明

本项目不是医疗设备。  
本项目不提供医疗建议。  
本项目不判断药品种类、剂量或治疗方案。  
本项目仅用于提醒用户和记录用户是否已确认服药。  
请始终遵循医生或药师的建议。

## 英文声明

This project is not a medical device.  
It does not provide medical advice.  
It does not determine medication type, dosage, or treatment.  
It only reminds the user and records whether the user has confirmed taking medicine.  
Always follow the instructions from your doctor or pharmacist.

## 禁止宣传口径

- 防止漏服
- 保证按时服药
- 医疗级提醒
- 可替代护理人员
- 自动识别药品
- 自动判断剂量

## 可用宣传口径

- 本地服药提醒
- 本地确认记录
- 离线优先
- 开源硬件
- 开源固件
- 帮助减少遗忘
