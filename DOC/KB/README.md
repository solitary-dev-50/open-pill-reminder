# Open Pill Reminder 知识库

## 说明

本目录基于项目根目录下的 `知识库.txt` 整理而成。

目标不是保留所有草稿内容，而是提炼出一套可直接指导开发、文档撰写和开源发布的统一口径。

## 使用原则

1. 这里的文档服务于第一版开发，不服务于长期脑暴
2. 如果原始草稿与当前已确认需求冲突，以当前已确认需求为准
3. 如果知识库与正式设计文档冲突，以正式设计文档为准

## 当前第一版统一口径

- 设备定位：离线优先、本地提醒、本地确认记录
- 不是医疗设备，不提供医疗建议
- 用户可在 Web 页面自由添加每日提醒时间
- 每天最多支持 8 个提醒
- 每个提醒包含 `id`、`time`、`enabled`
- 到点后触发蜂鸣器、LED、OLED 提醒
- 用户按确认键后记录已确认和确认时间
- 未确认时按 `repeat_interval_minutes` 重复提醒，最多 `max_repeat_count` 次
- 所有配置与记录本地保存

## 原始草稿中已收敛或暂不采纳的点

- `RTC + 纽扣电池`：可作为硬件增强项，不作为当前第一版强制前提
- `buzzer_enabled / led_enabled` 配置开关：当前第一版不作为核心需求
- `清除今日记录`：不作为第一版核心功能
- `导出记录`：不作为第一版核心功能
- `错过提醒 30 分钟内补提醒`：当前不作为既定规则
- `禁止重复时间`：当前未作为强制规则，若实现层需要简化，可后续再定
