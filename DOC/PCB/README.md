## 结构约束

这块 PCB 有一个重要前提：

- 目标为适配树莓派 `Raspberry Pi 4B` 外壳

因此在 PCB 设计时，需要同时满足以下约束：

- PCB 外形与外壳内部空间匹配
- PCB 安装孔位与外壳固定孔位匹配
- `USB-C` 接口位置与外壳开孔匹配
- `OK` / `SET` 按键位置与外壳按键孔匹配

这意味着后续 PCB 修订时，不能只看电气连通性，还要同时检查：

- 板框
- 孔位
- 接口朝向
- 按键位置
- 外壳装配可行性
